## 📌 Project Overview

This project presents an **interactive dashboard** for analyzing the **2026 Formula 1 World Drivers Championship (WDC)**.

The dashboard was developed using **Streamlit** and **Plotly** to visualize driver performance, constructor standings, race progression, wins, podiums, and finishing statistics throughout the season.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/reginasnp/F1-WDC-2026.git
```

Go to project directory

```bash
cd F1-WDC-2026
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Streamlit

```bash
streamlit run app.py
```
